دستیار هوشمندی که از محتوای خودِ سایت شما پاسخ می‌دهد. An AI assistant that answers from your own site content.

== Description ==

**دستیار هوشمند Yuniq.ai** سایت وردپرسی شما را به یک دستیار تعاملی تبدیل می‌کند که به‌جای پاسخ‌های عمومی، از محتوای واقعی سایت شما جواب می‌دهد.

افزونه محتوای سایت را ایندکس می‌کند و آن را به‌عنوان پایگاه دانش در اختیار مدل هوش مصنوعی می‌گذارد، بنابراین پاسخ‌ها به محصولات، خدمات و مقالات خودِ شما ارجاع دارند.

= امکانات =

* **اتصال به کارشناس انسانی:** دکمه‌ی ثابت «صحبت با کارشناس» و پیشنهاد خودکار وقتی هوش مصنوعی نتواند کمک کند؛ پنل اختصاصی «پشتیبانی زنده» در مدیریت با اعلان ایمیل و تلگرام
* **کارت محصول هوشمند:** وقتی هوش مصنوعی محصولی از ووکامرس را پیشنهاد می‌دهد، کارت واقعی با قیمت، موجودی و دکمه خرید نمایش می‌دهد
* **فرم دریافت سرنخ داخل گفتگو:** فرم مشاوره/تماس قابل تنظیم که در لحظه‌ی مناسب داخل چت ظاهر می‌شود؛ سرنخ‌ها در پنل مدیریت ذخیره می‌شوند
* **حالت صفحه‌ی کامل:** با شورت‌کد `[yuniq_ai_page]` دستیار را به‌جای حباب شناور، به‌صورت یک صفحه‌ی اختصاصی نمایش دهید
* **رابط کاربری مدرن:** طراحی Clean SaaS، حالت تاریک، حلقه‌ی درخشان اختصاصی روی دکمه شناور، و انیمیشن اختیاری با GSAP که فقط هنگام باز شدن پنل لود می‌شود
* **بدون هیچ درخواست خارجی:** فونت وزیرمتن و کتابخانه انیمیشن از دامنه‌ی خود سایت سرو می‌شوند — مناسب برای ایران و بدون مشکل GDPR
* **دسترسی‌پذیری:** ناوبری کامل با کیبورد، تله‌ی فوکوس، پشتیبانی از prefers-reduced-motion و صفحه‌خوان‌ها
* **پاسخ تدریجی (streaming):** جواب کلمه‌به‌کلمه نمایش داده می‌شود و کاربر منتظر پایان تولید نمی‌ماند
* **ایندکس دسته‌ای:** سایت‌های بزرگ بدون timeout ایندکس می‌شوند، با نوار پیشرفت واقعی و امکان توقف
* **جست‌وجوی بهینه‌شده برای فارسی:** یکسان‌سازی ی/ي، ک/ك، نیم‌فاصله و ارقام فارسی/عربی
* ویجت شناور با موقعیت قابل تنظیم (چهار گوشه یا مختصات دلخواه)
* پایگاه دانش خودکار از نوشته‌ها، برگه‌ها، محصولات ووکامرس و دسته‌بندی‌ها
* سازگار با OpenAI و هر سرویس سازگار با chat-completions (از جمله سرویس‌های ایرانی ریالی)
* فیلتر مسیرها برای انتخاب دقیق صفحات قابل ایندکس
* بخش ویدیوی معرفی داخل پنل گفتگو
* کارت‌های اقدام سریع برای پرسش‌های پرتکرار
* سفارشی‌سازی رنگ، اندازه و انیمیشن
* داشبورد آمار گفتگوها
* رابط کاملاً فارسی با پشتیبانی RTL

= برای توسعه‌دهندگان =

افزونه کلاس‌محور و با namespace نوشته شده (`Yuniq\Ai`) و از PSR-4 پیروی می‌کند. نقاط توسعه:

* `yuniq_ai_provider` — جایگزینی کامل ارائه‌دهنده هوش مصنوعی با پیاده‌سازی `AiProviderInterface`
* `yuniq_ai_system_prompt` — تغییر پرامپت سیستم و متن پایگاه دانش
* `yuniq_ai_api_request_args` — تغییر پارامترهای درخواست HTTP
* `yuniq_ai_is_active` — کنترل نمایش ویجت در هر درخواست
* `yuniq_ai_powered_by_html` — تغییر یا حذف امضای زیر پنل
* `yuniq_ai_client_ip` — تعیین IP پشت پراکسی یا CDN
* `yuniq_ai_booted` — دسترسی به سرویس‌کانتینر پس از راه‌اندازی
* `yuniq_ai_notify_channels` — افزودن کانال اعلان سفارشی برای پشتیبانی زنده (علاوه بر ایمیل و تلگرام)

== Installation ==

1. پوشه `yuniq-ai` را در `/wp-content/plugins/` آپلود کنید.
2. افزونه را از منوی افزونه‌ها فعال کنید.
3. به **Yuniq.ai ← تنظیمات** بروید و کلید API و آدرس سرویس هوش مصنوعی خود را وارد کنید.
4. در تب **خزنده محتوا** مشخص کنید چه محتوایی ایندکس شود.
5. به **پایگاه دانش** بروید و **شروع ایندکس‌گذاری** را بزنید.

== Frequently Asked Questions ==

= آیا افزونه کلید API همراه خود دارد؟ =

خیر. هیچ کلیدی همراه افزونه ارسال نمی‌شود. باید کلید API خودتان را در تنظیمات وارد کنید و هزینه مصرف بر عهده صاحب همان کلید است.

= با چه سرویس‌هایی کار می‌کند؟ =

با OpenAI و هر سرویسی که از API سازگار با `chat/completions` پشتیبانی کند. برای سرویس‌هایی با ساختار متفاوت می‌توانید با فیلتر `yuniq_ai_provider` یک ارائه‌دهنده سفارشی معرفی کنید.

= آیا از ووکامرس پشتیبانی می‌شود؟ =

بله. در صورت نصب ووکامرس، محصولات به‌همراه قیمت، SKU و وضعیت موجودی ایندکس می‌شوند.

= هنگام حذف افزونه چه بر سر داده‌ها می‌آید؟ =

غیرفعال‌سازی داده‌ها را نگه می‌دارد. حذف کامل افزونه تمام جدول‌ها و تنظیمات را پاک می‌کند.
