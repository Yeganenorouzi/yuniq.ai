دستیار هوشمندی که از محتوای خودِ سایت شما پاسخ می‌دهد. An AI assistant that answers from your own site content.

== Description ==

**دستیار هوشمند Yuniq.ai** سایت وردپرسی شما را به یک دستیار تعاملی تبدیل می‌کند که به‌جای پاسخ‌های عمومی، از محتوای واقعی سایت شما جواب می‌دهد.

افزونه محتوای سایت را ایندکس می‌کند و آن را به‌عنوان پایگاه دانش در اختیار مدل هوش مصنوعی می‌گذارد، بنابراین پاسخ‌ها به محصولات، خدمات و مقالات خودِ شما ارجاع دارند.

= امکانات =

* **اتصال به کارشناس انسانی:** دکمه‌ی ثابت «صحبت با کارشناس» و پیشنهاد خودکار وقتی هوش مصنوعی نتواند کمک کند؛ پنل اختصاصی «پشتیبانی زنده» در مدیریت با اعلان ایمیل و تلگرام
* **کارت محصول هوشمند:** وقتی هوش مصنوعی محصولی از ووکامرس را پیشنهاد می‌دهد، کارت واقعی با قیمت، موجودی و دکمه خرید نمایش می‌دهد
* **فرم دریافت سرنخ داخل گفتگو:** فرم مشاوره/تماس قابل تنظیم که در لحظه‌ی مناسب داخل چت ظاهر می‌شود؛ سرنخ‌ها در پنل مدیریت ذخیره می‌شوند
* **حالت صفحه‌ی کامل:** با شورت‌کد `[yuniq_ai_page]` دستیار را به‌جای حباب شناور، به‌صورت یک صفحه‌ی اختصاصی نمایش دهید
* **رابط کاربری مدرن:** طراحی Clean SaaS، حالت تاریک، حلقه‌ی درخشان اختصاصی روی دکمه شناور، و انیمیشن اختیاری با GSAP که فقط هنگام باز شدن پنل لود می‌شود
* **بدون هیچ درخواست خارجی:** فونت وزیرمتن و کتابخانه انیمیشن از دامنه‌ی خود سایت سرو می‌شوند — مناسب برای ایران و بدون مشکل GDPR
* **دسترسی‌پذیری:** ناوبری کامل با کیبورد، تله‌ی فوکوس، پشتیبانی از prefers-reduced-motion و صفحه‌خوان‌ها
* **پاسخ تدریجی (streaming):** جواب کلمه‌به‌کلمه نمایش داده می‌شود و کاربر منتظر پایان تولید نمی‌ماند
* **ایندکس دسته‌ای:** سایت‌های بزرگ بدون timeout ایندکس می‌شوند، با نوار پیشرفت واقعی و امکان توقف
* **جست‌وجوی بهینه‌شده برای فارسی:** یکسان‌سازی ی/ي، ک/ك، نیم‌فاصله و ارقام فارسی/عربی
* ویجت شناور با موقعیت قابل تنظیم (چهار گوشه یا مختصات دلخواه)
* پایگاه دانش خودکار از نوشته‌ها، برگه‌ها، محصولات ووکامرس و دسته‌بندی‌ها
* هر نوع پست سفارشی (JetEngine، ACF یا هر روش دیگر) قابل انتخاب و ایندکس است؛ فیلدهای سفارشی هر کدام تک‌به‌تک با برچسب منبع قابل انتخاب‌اند
* سازگار با OpenAI و هر سرویس سازگار با chat-completions (از جمله سرویس‌های ایرانی ریالی)
* فیلتر مسیرها برای انتخاب دقیق صفحات قابل ایندکس
* بخش ویدیوی معرفی داخل پنل گفتگو
* کارت‌های اقدام سریع برای پرسش‌های پرتکرار
* سفارشی‌سازی رنگ، اندازه و انیمیشن
* داشبورد آمار گفتگوها
* رابط کاملاً فارسی با پشتیبانی RTL

= برای توسعه‌دهندگان =

افزونه کلاس‌محور و با namespace نوشته شده (`Yuniq\Ai`) و از PSR-4 پیروی می‌کند. نقاط توسعه:

* `yuniq_ai_provider` — جایگزینی کامل ارائه‌دهنده هوش مصنوعی با پیاده‌سازی `AiProviderInterface`
* `yuniq_ai_system_prompt` — تغییر پرامپت سیستم و متن پایگاه دانش
* `yuniq_ai_api_request_args` — تغییر پارامترهای درخواست HTTP
* `yuniq_ai_is_active` — کنترل نمایش ویجت در هر درخواست
* `yuniq_ai_powered_by_html` — تغییر یا حذف امضای زیر پنل
* `yuniq_ai_client_ip` — تعیین IP پشت پراکسی یا CDN
* `yuniq_ai_booted` — دسترسی به سرویس‌کانتینر پس از راه‌اندازی
* `yuniq_ai_notify_channels` — افزودن کانال اعلان سفارشی برای پشتیبانی زنده (علاوه بر ایمیل، تلگرام و بله)

== Installation ==

1. پوشه `yuniq-ai` را در `/wp-content/plugins/` آپلود کنید.
2. افزونه را از منوی افزونه‌ها فعال کنید.
3. به **Yuniq.ai ← تنظیمات** بروید و کلید API و آدرس سرویس هوش مصنوعی خود را وارد کنید.
4. در تب **خزنده محتوا** مشخص کنید چه محتوایی ایندکس شود.
5. به **پایگاه دانش** بروید و **شروع ایندکس‌گذاری** را بزنید.

== Frequently Asked Questions ==

= آیا افزونه کلید API همراه خود دارد؟ =

خیر. هیچ کلیدی همراه افزونه ارسال نمی‌شود. باید کلید API خودتان را در تنظیمات وارد کنید و هزینه مصرف بر عهده صاحب همان کلید است.

= با چه سرویس‌هایی کار می‌کند؟ =

با OpenAI و هر سرویسی که از API سازگار با `chat/completions` پشتیبانی کند. برای سرویس‌هایی با ساختار متفاوت می‌توانید با فیلتر `yuniq_ai_provider` یک ارائه‌دهنده سفارشی معرفی کنید.

= آیا از ووکامرس پشتیبانی می‌شود؟ =

بله. در صورت نصب ووکامرس، محصولات به‌همراه قیمت، SKU و وضعیت موجودی ایندکس می‌شوند.

= هنگام حذف افزونه چه بر سر داده‌ها می‌آید؟ =

غیرفعال‌سازی داده‌ها را نگه می‌دارد. حذف کامل افزونه تمام جدول‌ها و تنظیمات را پاک می‌کند.

== Changelog ==

= 1.6.3 =
* رفع ایراد اصلی قفل راه‌اندازی: روی سایتی که از قبل افزونه را فعال داشت (و فعال‌سازی دوباره‌ای اتفاق نیفتاده بود)، قفل هیچ‌وقت درست فعال نمی‌شد و منوی پایگاه دانش/آمار/پشتیبانی زنده/وضعیت همیشه دیده می‌شدند، حتی اگر راه‌اندازی تمام نشده بود. حالا قفل‌بودن مستقیماً از روی وضعیت واقعی ۴ مرحله محاسبه می‌شود (نه یک پرچم ذخیره‌شده‌ی قدیمی)، پس همیشه با واقعیت یکی است.
* **بازطراحی راه‌اندازی:** هر کدام از ۴ مرحله حالا واقعاً صفحه مجزای خودش را دارد (نه ۳ صفحه با دو مرحله ترکیبی) — ذخیره کلید API صفحه را می‌برد به «تست اتصال»، تست موفق یک دکمه «مرحله بعد» باز می‌کند که می‌برد به «ایندکس محتوا»، و همین‌طور. لینک راهنما (برای دریافت کلید API یا رفع خطا) روی تمام ۴ مرحله دیده می‌شود، نه فقط ابتدای کار.
* **اعلان بله (پیام‌رسان ایرانی) اضافه شد:** مثل تلگرام، با توکن ربات و شناسه چت، در تب «پشتیبانی زنده».
* راهنمای کامل فعال‌سازی اعلان‌ها (ایمیل بدون اسپم، ساخت ربات تلگرام، ساخت ربات بله) به صفحه «راهنما» اضافه شد؛ کنار فیلدهای تلگرام و بله در تنظیمات هم لینک مستقیم به همان بخش گذاشته شد.
* رفع ایراد: در مرحله اول راه‌اندازی (کلید API)، بعد از ذخیره هیچ پیام تاییدی نشان داده نمی‌شد و کلید به‌صورت نقطه‌چین با همان ظاهر قبلی می‌ماند — به نظر می‌رسید ذخیره نشده. حالا بعد از ذخیره «تنظیمات ذخیره شد» نشان داده می‌شود و کنار فیلد کلید هم وضعیت «ذخیره‌شده/ذخیره‌نشده» واضح است.
* **راه‌اندازی اجباری و قدم‌به‌قدم:** بعد از فعال‌سازی افزونه، تا کلید API وارد و تست نشود، محتوای سایت ایندکس نشود و دستیار روشن نشود، به هیچ بخش دیگری از افزونه (پایگاه دانش، آمار، پشتیبانی زنده، وضعیت) دسترسی نیست — همان صفحه تنظیمات به‌جای حالت عادی، همین مراحل را یکی‌یکی نشان می‌دهد و با تمام‌شدن هر قدم، قدم بعد باز می‌شود. سایت‌هایی که قبلاً افزونه را راه‌اندازی کرده بودند، درگیر این قفل نمی‌شوند.
* بازبینی کامل افزونه: دستیار هوشمند روی سایت تازه‌فعال‌شده دیگر پیش از وارد کردن کلید API به‌صورت پیش‌فرض روشن نیست — تا خودتان آن را در قدم ۴ راه‌اندازی روشن نکنید، بازدیدکننده‌ها حباب گفتگوی ناکارآمد نمی‌بینند.
* رفع ایراد اصلی اعلان‌های پشتیبانی زنده: قبلاً علاوه بر وارد کردن ایمیل/توکن تلگرام، یک چک‌باکس جدای «فعال‌سازی» هر کانال هم لازم بود که اگر فراموش می‌شد (مخصوصاً برای تلگرام، که هیچ‌وقت پیش‌فرض فعال نبود) هیچ اعلانی ارسال نمی‌شد و هیچ خطایی هم دیده نمی‌شد. حالا همین که ایمیل یا توکن و شناسه چت تلگرام را درست پر و ذخیره کنید، همان کانال خودکار فعال می‌شود؛ چک‌باکس جدا حذف شد.
* راهنمای تلگرام: تاکید روشن که باید یک‌بار دکمه Start را به ربات خودتان در تلگرام بزنید، وگرنه با توکن و شناسه چت درست هم هیچ پیامی نمی‌رسد (پرتکرارترین دلیل واقعی «هیچی نمیده»).
* صفحه «وضعیت و خطاها» و دکمه «ارسال اعلان آزمایشی» حالا دقیقاً با همین منطق تازه هماهنگ‌اند؛ تلگرامِ تنظیم‌نشده دیگر به‌اشتباه کل وضعیت را «خطا» نشان نمی‌دهد.
* انواع پست سفارشی ساخته‌شده با JetEngine، ACF یا هر روش دیگری حالا در تب «خزنده محتوا» قابل انتخاب‌اند؛ از جمله یک پست‌تایپ محصول اختصاصی (بدون ووکامرس) که قبلاً همیشه از لیست کنار گذاشته می‌شد.
* بخش تازه «کدام فیلدها را بداند؟»: برای هر نوع محتوای انتخاب‌شده، فیلدهای سفارشی‌ای که واقعاً مقدار دارند تک‌به‌تک لیست می‌شوند، با برچسب منبع هرکدام (ACF، احتمالاً JetEngine، یا فیلد سفارشی عمومی) و یک نمونه مقدار؛ هر فیلد را جدا می‌توان از ایندکس کنار گذاشت.
* فعال‌سازی افزونه برای اولین بار حالا مستقیم به صفحه راهنمای راه‌اندازی می‌برد؛ قدم‌به‌قدم شدن نصب به‌جای رها کردن مدیر در فهرست افزونه‌ها.
* اگر «فعال‌سازی دستیار» بدون وارد کردن کلید API تیک زده شود، قبل از ذخیره یک بار هشدار داده می‌شود (پاسخ ندادن دستیار برای بازدیدکنندگان).
* وقتی پاسخ هوش مصنوعی کافی نبود، گزینه «صحبت با کارشناس» حالا به‌جای یک کادر جدا، به همان ردیف پیشنهادهای زیر پاسخ اضافه می‌شود؛ در حالت بدون‌استریم هم مثل حالت استریم رفتار می‌کند (قبلاً در آن حالت پیشنهادها را کامل حذف می‌کرد).
* سخت‌تر شدن امنیت گفتگوی پشتیبانی زنده: شناسه نشست در مرورگرهای بدون HTTPS دیگر با Math.random ساخته نمی‌شود (قابل پیش‌بینی)، حداقل طول شناسه پذیرفته‌شده در سرور بالاتر رفت، و مسیر دریافت پیام‌های گفتگو حالا مثل مسیرهای دیگر محدودیت نرخ درخواست دارد.

* امنیت: رفع تزریق کد از طریق لینک در پاسخ‌ها، جلوگیری از جعل نقش «system» در تاریخچه گفتگو، محدودیت نرخ برای فرم سرنخ و درخواست کارشناس، نمایش ایمن پیام‌ها در صندوق پشتیبانی.
* رفع ایرادها: دکمه «صحبت با کارشناس» پیش از اولین پیام، محدودکننده نرخ که کاربر را برای همیشه مسدود می‌کرد، قفل‌شدن اسکرول سایت در دسکتاپ، مکان‌نمای چشمک‌زن باقی‌مانده، پاک‌شدن بک‌اسلش CSS سفارشی پس از هر ایندکس، حذف‌نشدن همه کارت‌های اقدام سریع، دکمه سبد خرید برای محصول ناموجود/متغیر، قیمت بدون واحد پول.
* سرعت: حذف preload فونت، بارگذاری defer اسکریپت، درخواست اضافه در هر بازدید حذف شد، توقف polling در تب غیرفعال.
* پنل مدیریت: نوار ذخیره ثابت با نشانگر تغییرات ذخیره‌نشده (و Ctrl+S)، صندوق پشتیبانی بدون پرش، تاریخ‌ها به قالب سایت.
